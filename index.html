One live subscription, one viewer. A six-digit code pairs the two devices; audio and video go straight from device to device.

  1. Broadcaster starts the stream and gets a 6-digit code.
  2. Viewer types that code — no reply code to send back.
  3. Broadcaster accepts the viewer and video + sound start flowing device → device.

Works over HTTPS or on localhost. A tiny relay holds the WebRTC handshake for a few minutes; the media is peer-to-peer. Both devices need a network path to each other — public STUN is used, symmetric NATs would require a TURN server.
